# 📦 Inventory Management System

A full-stack Inventory Management System built with **Node.js**, **Express**, and **Microsoft SQL Server (MSSQL)**. This application manages inventory data, customer records, products, and orders through an interactive web interface.

---

## 🚀 Features

- **Product & Inventory Tracking:** View and manage product lines and stock details.
- **Order & Payment Processing:** Manage customer orders, order details, and payment histories.
- **User Authentication / Registration:** Dedicated user registration and login workflows.
- **Database Integration:** Powered by SQL Server with structured schemas and relational models.

---

## 🛠️ Tech Stack

- **Backend:** Node.js
- **Database:** Microsoft SQL Server (SSMS), `mssql` client
- **Frontend:** HTML5, CSS3, JavaScript (Static pages in `/public`)

---

## 📋 Prerequisites

Before running the project locally, ensure you have:
1. [Node.js](https://nodejs.org/) installed (v16 or higher).
2. [SQL Server](https://www.microsoft.com/en-us/sql-server/sql-server-downloads) & [SQL Server Management Studio (SSMS)](https://learn.microsoft.com/en-us/sql/ssms/download-sql-server-management-studio-ssms).

---

## ⚙️ Installation & Setup Guide

### 1. Database Setup
1. Open **SQL Server Management Studio (SSMS)** and connect to your SQL Server instance (`SQLEXPRESS` / `localhost`).
2. Open the file **`database.sql`** located in the root of this project.
3. Click **Execute** (`F5`) to create the `Inventory_management_system` database and all required tables/data.
